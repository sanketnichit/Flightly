# Flightly ✈️

A simple Android flight itinerary UI built with Kotlin, XML and Skyscanner Backpack.

## Features

- Flight information card
- Departure airport and time
- Arrival airport and time
- Backpack UI components
- Android XML View system
- ConstraintLayout-based design

## Tech Stack

- Kotlin
- Android
- XML
- ConstraintLayout
- Skyscanner Backpack
